Respaldos de Base de Datos

Copias de seguridad automáticas de todo — huéspedes, órdenes, inventario, personal — guardadas regularmente en caso de que algo salga mal.

Incremental

Una copia rápida y frecuente — se guarda por algunas semanas. Esto es lo que usaría para recuperar algo de los últimos días, como una orden o un check-in ingresado por error.

Completo

Una copia completa de todo el sistema — se guarda por meses. Esta es la red de seguridad a largo plazo, para retroceder más de lo que permiten las copias rápidas.

Restaurar desde un Respaldo

Si el sistema se dañó o se perdió información, suba un respaldo (.json.gz) — por ejemplo el del día anterior desde una USB o la nube — o presione Restaurar en uno de la lista de abajo. Primero verá un resumen para confirmar que es el correcto; antes de reemplazar nada se guarda una copia de los datos actuales.
